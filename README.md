# Pink & Grey Unisex Salon

Futuristic, fully animated website for Pink & Grey Unisex Salon, Narendrapur, Kolkata.

Built with React 18, Vite, Framer Motion and React Router.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy (Vercel)

Import this repo on Vercel. Framework preset: **Vite** (build `npm run build`, output `dist`).
`vercel.json` rewrites all routes to `index.html` so pages like `/about` work on refresh.
